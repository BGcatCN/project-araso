# 附章：音游窝是什么？

音游窝通常指的是音游玩家更常聚集、维护和交流的一类店铺环境。

它不一定是正式名称，而更像是玩家之间形成的共识标签。你在街机地图里看到它，通常意味着这家店对音游玩家更友好，也更容易获取一些经验和帮助。

## 这个标签意味着什么

- 更容易遇到熟悉机台和玩法的玩家。
- 店内对音游机台的维护和排队秩序通常更成熟。
- 新人如果有问题，往往更容易获得口头帮助。

知道“音游窝”是什么就够继续往下看了，不需要把所有社区细节都先弄懂。
