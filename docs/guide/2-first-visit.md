# 初次见面

在本章，我们将会介绍一些在第一次进入店铺前的建议，以及一些在店铺内的基本常识。

## 加入本地玩家群

加入本地的玩家群有许多的好处，你可以在群中直接询问某个店铺排队几人，机况如何，是否有活动等等，这些都是在街机地图上无法得知的信息。

需要注意的是，一些地区的玩家主要讨论可能已经转移到了特定的店铺群中，这时候便建议你加入你常驻的店铺的群聊了。

## Where is my mai? 2.0

在上一章中，我们已经通过街机地图找到了附近有maimai DX机台的店铺，但是，maimai DX在店铺的哪里呢？

一般来说，maimai DX机台会被放置在店铺的显眼位置，通常是店铺的入口处或者是店铺的中心位置。

这是为了引流，maimai DX作为一款非常受欢迎的街机音游，能够吸引大量的固定玩家进入店铺，从而带动店铺内其他机台的生意。

当然也有例外，有些店铺可能会将maimai DX机台放置在店铺的角落，或是专门的音游区内，这时候就需要玩家自己去寻找了。

## 游戏币的购买

在店铺内，玩家需要购买游戏币才能够进行游戏。一般来说，店铺会提供两种购买方式：线上团购和人工售币。并不推荐后者，人工售币的价格通常没有优惠，按照1元/枚的价格出售，仅推荐在少量买币时选择，我们着重介绍前者。

线上团购可以在平台（如抖音、快手、美团等）进行。一般来说，线上团购有两个特点：一次大量，价格优惠。通常情况下，线上团购都是100币起步，也有500币、1000币等更大数量的团购选项。往往越大越优惠。那么问题来了，一个人显然无法一次性购买并在短时间内消耗大量的游戏币，但大额团购的优惠又十分诱人，这时候该怎么办呢？

### 拼单

你可以在本地的玩家群寻找愿意和自己一起购买游戏币的玩家，大家一起购买大额团购，然后再按照每个人的实际出资进行分摊，这样既能够享受到大额团购的优惠，又能够避免游戏币过多而无法消耗的问题。
