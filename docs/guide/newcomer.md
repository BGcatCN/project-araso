# 初来乍到

Hello!!!

不管你是因为什么而选择游玩maimai DX这款游戏的，在此都欢迎你的到来！

相信你已经知道，maimai DX是一款**街机音游**，顾名思义，maimai DX在大多数时候只能在游戏厅找到，而并不是所有的游戏厅都有maimai DX的。

那么该如何快速的找到你所在地区有maimai DX的游戏厅呢？

## Where is my mai?

:::TIP
也可以使用街机地图微信小程序。
:::

运用[街机地图](https://map.bemanicn.com/)，我们可以快速地找到maimai DX。

方法一：选择按地区，然后选择自己的省份和区域，便可查找，大多数能列于此的游戏厅都有maimai DX。

方法二：登录账号后，选择按游戏，选择maimai DX后，在新的页面选择自己的省份和区域后，单击查询键。需要登录账号。

相信经过上面的步骤，你已经找到了哪里有maimai DX，可以看到，有一些店铺有着**音游窝**的标签，这又是什么呢？我们将在附章讲解。
