# 第一次进店前要知道什么

找到机厅之后，真正开始游玩前，你还需要知道几件很基础但很实用的事。

## 先观察机台状态

到店后先看机台是否正在维护、排队是否有默认顺序，以及周围玩家的节奏。

## 不确定时先问

如果你不知道怎样投币、怎样开始，或者当前是否轮到自己，直接礼貌地询问附近玩家通常是最快的方法。
